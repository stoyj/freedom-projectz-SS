# Freedom Projectz

Website for **Freedom Projectz**, a nonprofit organization active in Uganda and Bulgaria, founded by Tony and Joanne.

## Tech Stack

- HTML5, CSS3, Vanilla JavaScript (no frameworks)
- Component-based navigation and footer, loaded asynchronously
- Bilingual EN/BG interface with persisted language preference

## Features

- Fully responsive, mobile-first layout
- Custom dark-themed design system
- Multi-page structure: home, story, mission, projects, donate, contact

## Status

In active development. Core pages, navigation and the language switcher are complete; deployment and a contact form integration are in progress.
